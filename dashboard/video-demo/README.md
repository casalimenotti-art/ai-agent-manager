# Video demo (Remotion)

Carosello 3D di "foto" segnaposto con titolo, transizione e schermata finale (8 s, 1280x720). Si rifà con le foto vere dell'attività.

```bash
cd dashboard/video-demo
npm install
npm run studio     # anteprima nel browser
npm run render     # esporta out/demo.mp4
```

Serve Node 18+. Remotion ha una licenza con condizioni per uso commerciale in aziende: **leggila sul sito ufficiale prima di consegnare video a clienti paganti** (non verificata qui).
