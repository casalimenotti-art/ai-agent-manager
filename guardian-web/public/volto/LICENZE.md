# Provenienza degli strati del volto
Tutte le immagini di questa cartella sono generate da script del repository, con un design originale di NEXO
(NEXO Sentinel): `tools/volto3d/costruisci.py` e `tools/volto3d/strati.py`, Blender 5.3 con Cycles.
Non contengono asset esterni: niente texture, HDRI, modelli o font di terzi.
